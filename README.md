# 🎨 Superdesign Brasil — Biblioteca Pessoal de Prompts & Design Systems

> **Versão pessoal, 100% em Português e desbloqueada da biblioteca do Superdesign.**  
> Criada sob medida para leigos e profissionais transformarem ideias em páginas de vendas, painéis e aplicativos completos em minutos.

---

## 🌟 O que é este projeto?

A biblioteca do Superdesign original contém centenas de prompts e sistemas de design de classe mundial, mas impõe travas de cópia, limites de visualização de 100 itens e jargões técnicos complexos em inglês.

O **Superdesign Brasil** resolve isso entregando:
- **1.134 Prompts Completos de UI/UX** organizados em 10 categorias intuitivas.
- **147 Sistemas de Design (`design.md`)** com paletas de cores interativas (clique para copiar HEX) e regras de tipografia.
- **✨ Personalizador Mágico**: digite o nome do seu negócio e o nicho (ex: "Clínica Vida, Odontologia"), e o prompt é transformado instantaneamente em português pronto para ser usado.
- **Pré-visualização Interativa**: teste o site em tempo real nos modos Computador (Desktop), Tablet e Celular (Mobile).
- **Formatado para as melhores IAs**:
  - ⚡ **Lovable.dev**
  - ⚡ **Bolt.new**
  - ⚡ **v0 da Vercel**
  - 🤖 **ChatGPT (GPT-4o)**
  - 🧠 **Claude (Sonnet 3.5)**
  - 💻 **Cursor / Antigravity**
- **100% Grátis & Sem Bloqueios**: Zero paywalls, zero cadastro obrigatório.
- **Favoritos Salvos Localmente**: Guarde os modelos que mais gostar no seu próprio navegador.

## 🚀 Como Usar em 3 Passos Simples

1. **Escolha o Modelo**: Navegue pelas categorias ou busque pelo seu nicho na barra de busca (ex: *"barbearia"*, *"odontologia"*, *"dashboard financeiro"*).
2. **Abra o Personalizador Mágico**: Clique no card para abrir o estúdio. Digite o nome da sua empresa e o que ela faz.
3. **Copie e Cole**: Clique em **Copiar Prompt Personalizado** e cole no [Lovable.dev](https://lovable.dev), [Bolt.new](https://bolt.new), [v0.dev](https://v0.dev) ou ChatGPT!

## 💻 Desenvolvimento Local

```bash
# 1. Clone o repositório
git clone https://github.com/lbhubedu/superdesign-biblioteca-pt.git
cd superdesign-biblioteca-pt

# 2. Instale as dependências
npm install

# 3. Inicie o servidor de desenvolvimento
npm run dev

# 4. Gere o build de produção
npm run build
```
